# 四面64路腰臀围测量 Android App

原生 Android USB Host 应用，面向8片 WCH CH348八串口芯片，共64路。四个方向各16层传感器同步采集10秒，计算腰围、臀围和腰臀比，并显示人体轮廓。

## 功能

- 8片CH348、64路同时接收
- 固定串口参数：115200、8N1、无流控
- 解析 `distances= 268mm` 格式并实时显示
- 1920×1080横屏四列大字号界面，适配15.6寸工业平板
- 默认USB顺序：前上、前下、左上、左下、后上、后下、右上、右下
- 保存8块USB映射；有唯一序列号时按设备身份自动恢复，无唯一序列号时按Hub枚举位置恢复
- 上板A-H从上到下对应第1-8层，下板A-H从上到下对应第9-16层
- 四面同步测量10秒，自动拟合16层椭圆轮廓并计算腰臀围
- 原始和汇总CSV保存到Android的 `下载/串口距离记录`
- USB插拔检测、权限请求、断开提示

## 硬件要求

1. Android 10或更高版本，必须支持 USB Host/OTG。
2. 带独立电源的USB 2.0/3.0 Hub。不要依赖平板给64个雷达模块供电。
3. CH348 默认识别码为 VID `0x1A86`、PID `0x55D9`。
4. 四面各使用上、下两块CH348：上板A-H从上到下接第1-8层，下板A-H从上到下接第9-16层。
   第1层高度1235 mm，第16层高度635 mm，层间距40 mm。
5. 四列雷达测距基准面分别距离人体站立中心500 mm。

## 安装和首次使用

1. 安装 `app-debug.apk`。
2. 先给USB Hub和传感器上电，再通过OTG连接Android设备。
3. 按以下顺序连接Hub：前上、前下、左上、左下、后上、后下、右上、右下。
4. 打开App，依次允许8块CH348的USB访问。
5. 检查页面是否显示“全部在线 · 64/64”。
6. 首次使用时观察实时距离，确认四个方向及上下层正确；不正确时进入“USB映射”调整并保存。
7. 点击“开始四面测量（10秒）”，测量完成后查看腰围、臀围、腰臀比和轮廓。

## 构建

项目使用 Java 17、Gradle 8.9、Android Gradle Plugin 8.7.3、compileSdk 35。

```bash
gradle assembleDebug
```

APK输出：`app/build/outputs/apk/debug/app-debug.apk`

仓库包含 `.github/workflows/build-apk.yml`，推送到GitHub后会自动构建并上传APK artifact。

## 重要说明

CH348把8路串口复用在同一组USB Bulk端点中，并不是8个普通CH340。此项目包含用户态CH348协议实现。第一次连接真实硬件时，应核对设备VID/PID、端点地址和A-H顺序；若购买的板卡修改了PID，需要同步修改 `device_filter.xml` 和 `Ch348Device.java`。

8块板如果都没有唯一USB序列号，Android无法永久识别每一块外观相同的设备。APP会记住当前Hub设备路径和用户映射，但Hub整体断电、换插孔或重新枚举后仍应检查一次实时数据；建议固定Hub插孔和线缆标签。
